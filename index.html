Lab 1

Answer an onboarding policy question

Use the Employment Lifecycle Policy Advisor in Team Activity Center to answer a manager’s questions about equipment and account access.

Tasks

1 Open the advisor
  1. Sign in to the Fusion test environment using the workshop invitation.
  2. Follow Navigator → My Team → Team Activity Center.
  3. On the team page, find the Employment Lifecycle Policy Advisor card and select Ask Oracle.
2 Ask about equipment and access

Copy the prompt into How can I help you? and press Enter.

Prompt
A remote employee joins on Monday. Use only Sections 2 and 3 of the workshop’s Remote new starter onboarding policy. Use exactly two headings, “Section 2 — Equipment” and “Section 3 — Account access”. Under Section 2, give one bullet saying who opens the laptop request and how far in advance. Under Section 3, give one bullet saying who sends the account setup invitation and when. Then give one bullet combining the missing-invitation deadline with how the hiring manager follows up. State that deadline and action once under Section 3 and end the answer there. Use the policy’s relative deadlines exactly as written. Leave out calendar dates and weekdays.

Read the response for the equipment deadline, invitation timing, and follow-up action.

Open the shared onboarding policy

Help with this lab

If the card or Ask Oracle is missing, ask the workshop host to check your access. If the answer names a different policy or omits a deadline, show the host what you received.

Lab 2

Draft a first-week onboarding checklist

Use AI Assist in Journeys to generate three tasks for the same remote starter. Review the suggestions and exit before saving.

Tasks

1 Open Create Journey
  1. Sign in to the Fusion test environment using the workshop invitation.
  2. From the Fusion home page, go to My Client Groups → Journeys → Explore.
  3. Select Create Journey and choose AI Assist as the creation method.
  4. In Category, select On Boarding.
2 Generate task suggestions

Paste the brief into What type of template do you want to create? Select the AI Assist button below the text field and wait for Task suggestions.

Prompt
Create a first-week onboarding checklist for a remote employee who joins Monday. Include short worker-owned instructions for using the invitation to set up the work account, attending the team orientation, and reviewing work contact details in the HR profile. If the invitation is missing, the starter tells their hiring manager. Use only the details in this brief.

Open the shared onboarding policy

3 Review three tasks and cancel

Select one suggestion per topic. Look for actions the new starter can carry out.

Account setup
Use the invitation to set up the work account. Tell the hiring manager if it’s missing.
Team orientation
Find the orientation details and attend the session.
HR profile
Open the HR profile and review work contact details.

Select Cancel to close the form before saving and return to Explore.

Help with this lab

If Explore, Create Journey, AI Assist, or the On Boarding category is missing, ask the workshop host to check your access.

Remote new starter onboarding policy

Fictional workshop training policy · Version 1.0

1. Scope

This fictional policy applies to employees starting in a remote role. Use it to answer the workshop scenarios.

2. Equipment

The hiring manager opens an IT equipment request at least five business days before the employee's start date. The IT service desk ships the equipment and tracks delivery on that request.

3. Account access

The IT service desk sends the new starter a setup invitation before their first day. If the invitation is missing by noon in the new starter's local time on the last business day before their start date, the hiring manager follows up on the original IT ticket.

4. First week

The new starter completes account setup using the invitation, attends the team orientation, and reviews their work contact details in their HR profile. If the invitation or equipment is missing when they start, the new starter tells their hiring manager so the manager can follow up on the original IT ticket.
